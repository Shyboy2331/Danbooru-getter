# Danbooru 高清原图批量下载器 (万能高对比原生版)

一款专为 [Danbooru](https://danbooru.donmai.us/) 网站设计的无损高清画质批量提取与下载工具。脚本直接内嵌高对比度、防冲突的原生视觉样式，不仅解决了常规暗黑/白屏下的文字可读性问题，更支持各种字符格式的标签万能联想与提取。

---

## 🎨 核心功能

* 💎 **100% 原始画质提取**：完美解析并保存官方最标准的无损高清大图（即 `view original` 的满血规格），杜绝压缩图和缩略图。
* 🏷️ **万能联想检索**：支持对画师（Artist）、角色（Character）等任意类型的 Tag 进行模糊匹配、中日文或带括号等特殊字符的万能检索。
* 🔍 **智能页面捕获**：启动时自动提取当前正在浏览的页面标签或画师名称，免去二次复制粘贴的麻烦。
* 📦 **本地打包 ZIP / 连续顺序下载**：
  * **连续直接下载（推荐）**：单线程安全防限流队列连续拉取大图下载至系统默认路径下，稳定省心。
  * **打包 ZIP 压缩包**：支持一键将选中的高清图片压入 ZIP 并在前端直接生成导出，方便归档。
* 🛡️ **跨域请求特权（GM_xmlhttpRequest）**：使用油猴特权函数实现跨域无损下载，完美绕过主流浏览器对非同源静态资源的拦截及跨域 Referer 检验。

## 🛠️ 使用方法

1. 打开 [Danbooru](https://danbooru.donmai.us/) 网站任意页面。
2. 页面右下角会自动展示醒目的红色悬浮按钮：**`批量原图下载`**。
3. 点击打开控制面板：
   * 输入框默认会自动载入您当前浏览页面的相关 Tag。
   * 您也可以手动在输入框中打字，检索系统会自动为您展现模糊搜索联想下拉列表。
4. 点击 **`检索作品列表`**，脚本会安全分批拉取当前 Tag 下的所有作品元数据，并为您生成高保真的网格作品画廊。
5. 勾选需要下载的作品大图，选择 **连续直接下载** 或 **打包 ZIP**，即可一键批量收藏！

---

## 💡 注意事项

* **多文件下载权限**：第一次点击“连续直接下载”时，如果浏览器在地址栏或页面上方弹出 **“允许该网站下载多个文件”** 的提示，请务必点击 **【允许】**。
* **ZIP 性能提醒**：大图打包极度消耗设备的本地内存。如果下载大图数量超过 50 张，建议选择 **“连续直接下载原画”** 模式，避免浏览器因内存不足而白屏挂起。
* **下载间隔延迟**：内置防限流下载延迟间隔（默认 1000 毫秒），可根据您的网络质量和代理速度灵活调整，避免过于频繁拉取导致 IP 触发官方 429 限制。
